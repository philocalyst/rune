# Real owner-local obarrays

The tagged owner-local object is an actual name-to-Symbol namespace, not a hash-table stand-in, fabricated abbrev table, Lisp body replacement, or global native map of raw Lisp pointers. Original `obarray.el` and `abbrev.el` remain the implementations of abbrev behavior. Local symbols have ordinary independently rooted value/function/property identity, including names `nil`, `t`, and the empty string; they are not the global constants. Repeated intern returns the same member. Symbol lookup/removal requires exact membership identity; removing a member does not erase a still-retained symbol's value or properties.

Native primitive validation checks the obarray before the name. Invalid cyclic graphs remain the original objects in structured conditions, with no recursive diagnostic rendering. Unicode multibyte names and ASCII unibyte names are supported; non-ASCII unibyte names fail explicitly because the current Symbol representation cannot preserve their storage semantics. Property-bearing input names are rejected rather than silently dropping spans in the current Symbol-name representation. The identity/storage/properties of GNU `symbol-name` Strings are not claimed. Names are bounded to 64KiB before native owned copying; core capacity/entry limits also apply. SIZE is a nonnegative fixnum capacity hint, bounded to 65536; larger fixnums signal `args-out-of-range` with the original direct condition data, although GNU supports a larger hint domain. BigInts (including positive ones) fail `wholenump`, matching GNU CHECK_FIXNAT. The hint is not an unbounded allocation promise.

`mapatoms` snapshots at most 65536 Symbols into an ordinary traced owner vector before callbacks. No native table/global lock survives a callback or moving collection. Entries removed before visitation are skipped; additions are outside the initial snapshot. Callback validation is lazy, so an empty table accepts an otherwise invalid callback. Callback errors stop traversal and retain preceding effects. This is a qualified bounded traversal policy, not a claim about GNU's unspecified visit order or every mutation case.

Explicit local tables are supported. NIL/omitted obarray retains Rune's existing initial-global-namespace behavior; the genuine dynamically rebound `obarray` variable is not implemented. Removal from the global namespace and legacy vector obarrays are rejected explicitly. No empty local table is passed off as the initial global namespace. Raw byte Symbol names, full obarray default-variable semantics, arbitrary foreign-domain tables and serialized/transferred namespaces are not claimed. These limits must remain visible until their actual owner/representation contracts exist.

The bundled `lisp/obarray.el` is replaced byte-for-byte with official GNU Emacs 30.1 source (SHA256 `1a01cd04f035c59bd767e27b922b894aeeef3c41a909edad1118c049cf94319e`), preserving its full copyright/license. The previous bundled file was byte-identical to GNU29.1 and its Lisp `obarray-make`/`obarrayp` definitions overwrite native opaque-object functions during bootstrap. The GNU30 file supplies genuine helper functions and no such overrides. This is a pinned source-version upgrade, not a fake feature or a hand-rewritten helper body. Other bundled files are not represented as uniformly GNU30.
